# AdventureWorks-Sales-Analysis-SQL
# 📊 AdventureWorks Sales & KPI Analysis (SQL)

## 🚀 Project Overview
This project focuses on executing a comprehensive data analysis of the **AdventureWorks** relational database. The primary objective is to extract Key Performance Indicators (KPIs) and uncover actionable business insights regarding sales performance, product profitability, and customer behavior using advanced SQL queries.

## 🎯 Business Questions Answered
- What is the total revenue and profit generated across different regions?
- Which products are the top performers in terms of sales volume and revenue?
- How does sales performance compare year-over-year (YoY)?
- Who are the most valuable customers based on their purchasing history?

## 🛠️ Technical Skills & SQL Techniques
This project heavily relies on advanced SQL features within **SQL Server Management Studio (SSMS)**:
- **Complex Joins & Relationships:** Connecting multiple normalized tables (Sales, Products, Customers, Territories).
- **CTEs & Subqueries:** Structuring complex logic for better readability and performance.
- **Window Functions:** Utilizing `RANK()`, `DENSE_RANK()`, and `OVER()` partitions for ranking products and calculating running totals.
- **Data Aggregation:** Extensive use of `GROUP BY`, `HAVING`, and aggregate functions to compute KPIs.
